トバル2（PS1）・DuckStation 用ツール

JKガード監視
敵が覚えている技の回数を見る

トバル2のクエストモードで、敵が覚えている「技の回数の表」を小窓に表示するツールです。

Mac・Windows で動作確認済み

とりあえず触りたい人はここから
ダウンロード tobal2_jkguard.zip

ツール本体と技表（waza フォルダ）が入っています。展開したら 使い方 の手順で動かしてください。

更新履歴　Ver1　チュージ、エポン、フェイ、マリー、チャコの技表を追加

できること 使い方 画面の見方 注意 技の名前を登録する

できること

  • 表の10枠を表示「その敵だけのメモ」と「記憶ノート」。回数が増えた枠は赤く光ります
  • 今の技・敵の情報自分と敵の今の技、敵の名前、エリア、プレイ時間
  • ログを残す敵がガードした時や表が増えた時などを logs フォルダに保存
  • 検証用の書き換え表の枠を書き換える機能もあります（使わなければゲームには何もしません）

使い方

1

Python 3 を入れる

このツールは Python（パイソン） というプログラミング言語で書かれています。動かすには、パソコンに Python 3 を一度だけインストールしておく必要があります（無料）。

小窓の表示には tkinter（ティーキンター） という、Python に最初から付いてくる「ウィンドウを作る部品」を使っています。python.org のインストーラーで入れれば一緒に入るので、別に何かを入れる必要はありません。

Windows
  1. python.org/downloads を開き、黄色い「Download Python 3.x.x」ボタンからインストーラーをダウンロード
  2. インストーラーを開いたら、最初の画面の下にある 「Add python.exe to PATH」にチェック を入れてから「Install Now」
Mac
  1. 同じく python.org/downloads から macOS 用のインストーラー（.pkg）をダウンロードして、そのまま進めてインストール
  2. Homebrew で入れた Python は tkinter が入っていないことがあるので、python.org 版がおすすめです
Homebrew を使っている人へ　このツールに Homebrew は必要ありません。ただし Homebrew を使う場合は、2026-10-23 時点で必ず最新の状態にアップデートしてください（ターミナルで brew update）。2026年9月の Homebrew 7.0.0 で、セキュリティの問題が8件修正されています。
2

ツールをダウンロードして置く

  1. ページ上のボタンからダウンロードした zip を展開する（Windows: 右クリック →「すべて展開」、Mac: ダブルクリック）
  2. できた tobal2 フォルダを、デスクトップなど分かりやすい場所に置く。ガードのログは、この中にできる logs フォルダに保存されます
tobal2/
├ TOBAL2_duck_JKguard.py   ← ツール本体
└ waza/                    ← 技表（キャラごと）
   ├ 00_共通.json
   ├ 01_チュージ.json
   ├ …
   └ 10_ドクターV.json
ファイルを1つずつダウンロードする場合（技表だけ新しくしたい時など）

TOBAL2_duck_JKguard.py（ツール本体）

ブラウザに文字がずらっと表示された場合は、リンクを右クリック →「名前を付けてリンク先を保存」。技表はツールと同じ場所の waza フォルダに入れます。

00_共通.json 01_チュージ.json 02_エポン.json 03_グリン.json 04_オライムス.json 05_フェイ.json 06_ホム.json 07_マリー.json 08_イール.json 09_チャコ.json 10_ドクターV.json

緑の枠はIDを登録済みの技表です（全部の技ではありません）。それ以外は技名だけ入っていて、IDはまだ空です。00_共通.json は JK など全キャラ共通の技。waza フォルダが無くても動きます（技名が出ず、IDの数字だけになります）。

3

DuckStation の設定

設定 → デバッグ →「GDB サーバーを有効化」をオン（ポートは 2345 のまま）。最初に一度やればOKです。

4

実行する

ゲームを起動してから、下の手順でツールを実行します。コマンドを打つ画面（Windowsはコマンドプロンプト、Macはターミナル）を使いますが、打つのは1行だけです。

Windows
  1. エクスプローラーで、ツールを置いたフォルダを開く
  2. 上のアドレス欄（フォルダの場所が表示されている所）をクリックして、cmd と入力して Enter。そのフォルダで黒い画面（コマンドプロンプト）が開きます
  3. 次の1行を打って Enter 
    py TOBAL2_duck_JKguard.py

PowerShell でも同じコマンドで動きます。

Mac
  1. アプリケーション → ユーティリティ →「ターミナル」を開く
  2. python3 と打つ（最後に半角スペースを1つ）
  3. ダウンロードした TOBAL2_duck_JKguard.py をターミナルの画面にドラッグ＆ドロップ（ファイルの場所が自動で入ります）
  4. Enter

成功 小窓が出たらOK。終わる時は小窓を閉じてください（黒い画面も閉じてOK）。

画面の見方

表

アドレス 0x8012806C〜（1枠 = 技ID 2バイト + 回数 2バイト、10枠）

枠呼び方中身
枠0・1その敵だけのメモ1体の敵との戦闘で最初に出した2種類の技。敵が替わると空になる
枠2〜9記憶ノート3種類目以降に出した技。ハードリセットまで消えない
  • 回数は技を「出した時」に増えます（空振りでも）
  • ジャンプキック（JK）のIDは全キャラ共通で 0199
  • 記憶ノートのJKが6回前後を超えると、ガードする種類の敵にJKをガードされやすくなります
  • 技の名前が出るのは、技表にIDが登録済みの技だけです。それ以外はIDの数字だけが出ます（JKの回数はどのキャラでも見られます）
  • IDの上2桁でキャラが分かります（04xx=チュージ、08xx=エポン、0Exx=フェイ、10xx=マリー、16xx=チャコ）
  • 技の名前は トバル2 wiki の技表を参照しています

ボタン

ガード！／ガード無し／区切り
押した時刻と表の中身をログに残します。「ここからガードされ始めた」などの目印用
表示: 技名／コマンド
表・今の技・ログに出す文字を「技名」と「コマンド」（例: 方向+下）に切り替えます
書き込み
指定した枠に、好きな技IDと回数を書き込みます（例: 枠9にJKを8回） 検証用
技登録（右上）
技の名前を登録する窓を開きます（下で説明）
注意　書き込みはゲームのメモリを書き換えます。普通に遊ぶ・走る時は使わないでください。ハードリセットすれば表は元に戻ります。

注意

  • GDBサーバーには1本しか繋がらないので、他のGDBツールとは同時に使えません
  • ステートロードで表が入れ替わった時は、ログに「◆ステートロード？」と出ます（入れ替わりは技の増加として数えません）

技の名前を自分で登録する

見たい人だけ（クリックで開く）

技の名前とコマンドは、waza フォルダの技表（キャラごとの .json）に入っています。ファイル名の頭の番号は wiki のキャラの並び順です。技表は トバル2 wiki の技表と同じ並びで、1行が1つの技です。

{"分類": "上段技", "技名": "連捶掌", "コマンド": "上､上､上", "ID": ["1617", "1618", "1653"]},
  • 「ID」はその技を出した時に出るIDの並びです（連携技は1段ごとに別のIDになります）
  • IDが []（空）の技は、まだ調べていない技です
  • "スキップ": true が付いた技は、登録しないことにした技です（投げなど）

「技登録」ボタンで登録する

  1. DuckStation とツールを動かし、トレーニングモードなど落ち着いて技を出せる場所に行く
  2. 小窓の「技登録」ボタンを押すと、登録用の窓が開きます
  3. 左上でキャラの技表を選ぶと、まだIDが無い最初の技が表示されます
  4. 表示された技を出すと、出たIDが並びます
  5. 合っていれば「登録」（窓を選んだ状態で Enter）→ 技表に保存され、次の技に進みます
[09_チャコ ▼]  12/75 （ID登録済み 53  スキップ 0）
[上段技] 連捶掌
上､上､上
登録済みのID: なし
待機とみなすID: まだなし
済 1617 冲捶          ← 出たIDがここに並ぶ
済 1618 連捶
新 1653 （未登録）
[登録 (Enter)] [スキップ (S)] [やり直し (BS)] [← 前] [次 →] [待機の判定を消す]

並んだIDの色

  • 黄色の「済」＝他の技（または待機）で登録済み
  • 水色の「済」＝今の技に登録済み
  • 緑の「新」＝まだどの技にも登録されていないID

操作のコツ

  • 技と技の間を少し空けると、次に出した技から数え直します。途中で失敗したら「やり直し」（BackSpace）
  • キャラによって待機（立っているだけ）のIDが違います。待機IDがまだ無いキャラでは、技を出す前に1.5秒立っていると、そのIDを「待機」として技表の "待機ID" に保存し、並びから外します（表示も「待機」になります）。しゃがみなど他の待機を足したい時は、ID欄に入れて「このIDを待機にする」。間違えた時は「待機の判定を消す」
  • 登録しない技（投げなど）は「スキップ」（S）。技表に印が付き、次に窓を開いた時も飛ばされます。スキップした技でもう一度押すと印が外れます
  • 後で調べたい技は「次 →」（→）で1つ先へ。印は付かないので、次に窓を開いた時にまた出てきます
  • 間違えて登録したら「← 前」で戻って、出し直して「登録」（上書きされます）
  • 登録した内容はすぐ技表に保存され、表やログの技名にも反映されます

ノートの名前を直す・wikiに無い技を足す

登録窓の下の「ID」「技名」「コマンド」欄に入れてから、ボタンを押します。

ID [      ]  技名 [      ]  コマンド [      ]  [探す]
ノートの表示  [ノートに出る名前を変更]
技表          [wikiに無い技を足す] [この技を消す] [このIDを待機にする]

探す　ID欄にIDを入れて「探す」（または Enter）を押すと、そのIDを使っている技を表示します。ID欄が空なら、技名欄の文字を含む技を探します。今の技表に無ければ他のキャラの技表も探し、もう一度押すと次の候補に進みます

ノートの表示　小窓の表（ノート）に出る名前を直します

ノートに出る名前を変更
ノートに出ている ID（例: 0E26）をID欄に、出したい名前を技名欄・コマンド欄に入れて押します（コマンド欄が空なら今のコマンドのまま）。そのIDの表示だけが変わります（今の技・ログの表示も同じになります）。技表の "表示名" に保存されます。技名欄を空にして押すと元に戻ります

技表　技表の行を増やす・減らす、待機を決めます

wikiに無い技を足す
wikiに無い技を技表の最後に「技表に無い技」として足します。技名は必須、IDはID欄に入れる（連携技は 0E2D 0E2E のように空白か → で区切る）か、空のままその技を出せば出たIDの並びを使います
この技を消す
「wikiに無い技を足す」で足した技を、技表から消します（間違えて足した時用。確認が出ます）。wikiの技は消せないので、登録しない時は「スキップ」を使います
このIDを待機にする
そのIDを待機（立っているだけ等）として扱い、並びから外します
同じIDを使う技が複数ある時　表の表示名は ①そのIDが出るまでの段の数が少ない技 → ②同じ段の数なら、そのIDで終わる技 → ③技表で先に書いてある技 の順で決まります。

手で書き足す場合

技表の .json はテキストエディタで直接直すこともできます（ツールを閉じてから）。

  • Windows: 右クリック →「プログラムから開く」→「メモ帳」
  • Mac: 「CotEditor」や「Visual Studio Code」など、プログラム用のエディタがおすすめです（標準の「テキストエディット」は " が勝手に “ ” に変わって動かなくなることがあります）
書き方の注意　記号（" , [ ] { } :）は半角で。技の行の最後の , は、一番最後の技にだけ付けません。書き方を間違えると、起動した時にログに「○○.json が読めません」と出ます。
