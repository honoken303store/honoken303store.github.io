# トバル2 JKガード監視（DuckStation用）

トバル2（PS1）のクエストモードで、敵が覚えている「技の回数の表」を小窓に表示するツールです。
動画で使っているものと同じツールです。

- 表の10枠（「その敵だけのメモ」と「記憶ノート」）を表示し、回数が増えた枠を赤く光らせる
- 自分と敵の今の技、敵の名前、エリア、プレイ時間を表示
- 敵がガードした時や表が増えた時などをログに残す（`logs` フォルダに保存）
- 検証用に、表の枠を書き換える機能もあります（使わなければゲームには何もしません）

Mac・Windowsで動作確認済みです。自己責任でお使いください。

## 使い方

### 1. Python 3 を入れる

このツールは **Python（パイソン）** というプログラミング言語で書かれています。
動かすには、パソコンに Python 3 を一度だけインストールしておく必要があります（無料）。

小窓の表示には **tkinter（ティーキンター）** という、Python に最初から付いてくる「ウィンドウを作る部品」を使っています。
python.org のインストーラーで入れれば一緒に入るので、別に何かを入れる必要はありません。

- **Windows**
  1. https://www.python.org/downloads/ を開き、黄色い「Download Python 3.x.x」ボタンからインストーラーをダウンロード
  2. インストーラーを開いたら、最初の画面の下にある **「Add python.exe to PATH」にチェック** を入れてから「Install Now」
- **Mac**
  1. 同じく https://www.python.org/downloads/ から macOS 用のインストーラー（.pkg）をダウンロードして、そのまま進めてインストール
  2. Homebrew で入れた Python は tkinter が入っていないことがあるので、python.org 版がおすすめです

### 2. ツールをダウンロードして置く

1. [TOBAL2_duck_JKguard.py](TOBAL2_duck_JKguard.py) をダウンロード
   （ブラウザに文字がずらっと表示された場合は、リンクを右クリック →「名前を付けてリンク先を保存」）
2. 分かりやすい場所にフォルダを作って、その中に置く（例: デスクトップに `tobal2` フォルダ）
   - ガードのログは、このファイルと同じ場所にできる `logs` フォルダに保存されます

### 3. DuckStation の設定

設定 → デバッグ →「GDB サーバーを有効化」をオン（ポートは 2345 のまま）。最初に一度やればOKです。

### 4. 実行する

ゲームを起動してから、下の手順でツールを実行します。
コマンドを打つ画面（Windowsはコマンドプロンプト、Macはターミナル）を使いますが、打つのは1行だけです。

- **Windows**（コマンドプロンプトの代わりに PowerShell でも、同じコマンドで動きます）
  1. エクスプローラーで、ツールを置いたフォルダを開く
  2. 上のアドレス欄（フォルダの場所が表示されている所）をクリックして、`cmd` と入力して Enter
     → そのフォルダで黒い画面（コマンドプロンプト）が開きます
  3. 次の1行を打って Enter
     ```
     py TOBAL2_duck_JKguard.py
     ```
- **Mac**
  1. アプリケーション → ユーティリティ →「ターミナル」を開く
  2. `python3 ` と打つ（最後に半角スペースを1つ）
  3. ダウンロードした `TOBAL2_duck_JKguard.py` をターミナルの画面にドラッグ＆ドロップ（ファイルの場所が自動で入ります）
  4. Enter

小窓が出たら成功です。終わる時は小窓を閉じてください（黒い画面も閉じてOK）。

## 画面の見方

```
今の技 0199 JK   敵の技 0037        ← 自分と敵が今出している技のID
群  30   敵HP  100   timer  12       ← 技グループ値・敵のHP・表の手前にあるタイマー的な値
敵 BEAR
エリア 1E 遺跡  FLOOR 2   0:42:10
枠  ID    回数  技名
── その敵だけのメモ ──
 0  1622     3  端脚
 1  0000     0
── 記憶ノート ──
 2  0199     3  JK
 ...
[ガード！][ガード無し][区切り] [表示: 技名] □メモ（枠0・1）を空に固定
枠[9] ID(16進)[0199] 回数[8] [書き込み]
（ここにログが流れる）
```

### 表

```
アドレス 0x8012806C〜（1枠 = 技ID 2バイト + 回数 2バイト、10枠）

枠0・1  その敵だけのメモ   1体の敵との戦闘で最初に出した2種類の技。敵が替わると空になる
枠2〜9  記憶ノート         3種類目以降に出した技。ハードリセットまで消えない
```

- 回数は技を「出した時」に増えます（空振りでも）
- ジャンプキック（JK）のIDは全キャラ共通で `0199`
- 記憶ノートのJKが6回前後を超えると、ガードする種類の敵にJKをガードされやすくなります
- 技の名前が出るのは、共通技（JKなど）と**チャコの技**だけです。調べたのがチャコだけなので、
  エポン・マリーなど他のキャラの技はIDの数字だけが出ます（JKの回数はどのキャラでも見られます）
  - IDの上2桁でキャラが分かります（`08xx`=エポン、`10xx`=マリー、`16xx`=チャコ）
- 技の名前は [トバル2 wiki](https://w.atwiki.jp/tobal2/) の技表を参照しています

### ボタン

- **ガード！／ガード無し／区切り**: 押した時刻と表の中身をログに残します。「ここからガードされ始めた」などの目印用
- **表示: 技名／コマンド**: 表・今の技・ログに出す文字を「技名」と「コマンド」（例: `方向+下`）に切り替えます
- **メモ（枠0・1）を空に固定**: チェック中は枠0・1を空にし続けます。どの技も記憶ノートに入るようになります（検証用）
- **書き込み**: 指定した枠に、好きな技IDと回数を書き込みます（検証用。例: 枠9にJKを8回）

書き込みと固定はゲームのメモリを書き換えます。普通に遊ぶ・走る時は使わないでください。
ハードリセットすれば表は元に戻ります。

## 技の名前を自分で登録する

技の名前とコマンドは、`TOBAL2_duck_JKguard.py` の中にある `KNOWN_IDS` という表に直接書いてあります。
ここに1行足すと、その技のIDの横に名前（またはコマンド）が出るようになります。

### 1. 技のIDを調べる

ツールを動かしたまま、名前を調べたい技を出すと、小窓の一番上の「今の技」にその技のIDが出ます（例: `164C`）。
ログにも、技が変わるたびに緑色の行で残ります。

```
今の技 164C チャコ   敵の技 0037
```

- ジャンプキックのように、出している途中でIDが何回か変わる技もあります（JKは `00D1` → `019A` → `0199`）。
  迷ったら、表（技の回数の表）で回数が増えたIDが、その技のIDです

### 2. ファイルに書き足す

1. ツールを閉じてから、`TOBAL2_duck_JKguard.py` をテキストエディタで開く
   - Windows: 右クリック →「プログラムから開く」→「メモ帳」
   - Mac: 「CotEditor」や「Visual Studio Code」など、プログラム用のエディタがおすすめです
     （標準の「テキストエディット」は `"` が勝手に `“ ”` に変わって動かなくなることがあります）
2. `KNOWN_IDS = {` で検索すると、こんな表が見つかります

   ```python
   KNOWN_IDS = {
       0x0003: ("立ち", "立ち"), 0x0008: ("前歩き", "→"), 0x0009: ("横移動", "↑/↓"),
       ...
       0x164F: ("滑刃腿", "走り下"), 0x165A: ("裏斧刃脚", "後ろ向きで下"),
   }
   ```

3. 最後の `}` の前に、1行足す

   ```python
       0x164F: ("滑刃腿", "走り下"), 0x165A: ("裏斧刃脚", "後ろ向きで下"),
       0x0812: ("エポンの○○", "→→上"),
   }
   ```

   - 書き方は `0x` + 調べたID（4桁）、`:`、`("技名", "コマンド")`、`,`
   - コマンドが分からない時は `""`（空）でもOK。名前とコマンドの両方を `"` で囲み、間を `,` で区切ります
   - 連携技は1段ごとに別のIDなので、コマンドには「その段までの入力」を書きます（例: `"中､中"`）
   - 記号（`:` `"` `,` `(` `)`）は**半角**で。行の頭のスペースはあってもなくても動きます
   - 1行に何個並べてもOK
4. 保存して、ツールを起動し直す

起動した時にすぐ閉じてしまう・エラーが出る場合は、足した行の `"` `,` `(` `)` が抜けていないか、全角になっていないかを確認してください。

## 自分で作りたい人向け

下のプロンプトをAI（Claude・ChatGPTなど）に貼ると、このツールをシンプルにしたもの（表とJKの回数だけ）を作ってもらえます。
表示を変えたい・別の値も見たい、などは続けてAIに頼めば直してくれます。

````
DuckStation（PS1エミュレーター）のGDBサーバー（127.0.0.1:2345）に接続して、
トバル2のメモリを読み、小窓に表示するPythonツールを作ってください。

条件:
- Python 3 の標準ライブラリだけ（socket と tkinter）で、Windows・Macの両方で動くこと
- メモリは読むだけで書き込まない
- 接続したらGDBの "c" パケットを送ってエミュレーションを再開させる
- メモリ読み込みは "m<アドレス>,<サイズ>" パケット（アドレスは 0x80000000 + オフセット）
- 約16msごとに読み直して表示を更新し、DuckStationが起動していない時は1秒ごとに再接続
- 小窓は常に最前面

読む値（すべてリトルエンディアン）:
- 0x8012806C から 4バイト×10枠の表。1枠 = 技ID(u16) + 回数(u16)
  枠0・1は「その敵だけのメモ」、枠2〜9は「記憶ノート」として分けて表示する
- 技ID 0x0199 がジャンプキック。枠2〜9 のうちIDが0x0199の枠の回数を「ノートのJK」として大きく表示
- 0x8012602C（u16）= 敵の今の動作ID。0x013C になったら立ちガード、0x008D になったらしゃがみガード
  ガードになった瞬間に「時刻・ガードの種類・ノートのJK」をログ欄とテキストファイルに残す

表示:
- 上に「ノートのJK ○回」、その下に10枠の表（枠番号・ID(16進4桁)・回数）、一番下にログ
- 値が変わった枠は1秒くらい色を付ける
````

## 注意

- GDBサーバーには1本しか繋がらないので、他のGDBツールとは同時に使えません
- ステートロードで表が入れ替わった時は、ログに「◆ステートロード？」と出ます（入れ替わりは技の増加として数えません）
